# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, databases, networking, security, application development, analytics, and artificial intelligence. It is designed to support organizations in building, deploying, and managing applications and infrastructure in the cloud.

## Global Infrastructure

Azure organizes its infrastructure into geographies and regions. An Azure geography contains one or more regions and is designed to help organizations meet data residency and compliance requirements while keeping applications and data within appropriate geographic locations.

## Cloud Management Console

The Azure Portal is a web-based unified management console for creating and managing Azure resources. It provides a graphical interface for managing subscriptions and resources, building applications, configuring virtual machines and databases, and monitoring costs.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable virtual computing resources for running applications and workloads.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of unstructured data.

### 3. Azure SQL Database

Azure SQL Database is a managed relational database service for applications that require SQL-based data storage.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management capabilities for controlling access to applications and resources.

## Three Advantages

1. **Microsoft ecosystem integration** – Azure is well suited for organizations already using Microsoft technologies and services.
2. **Global infrastructure** – Azure provides geographically distributed infrastructure designed to support availability, data residency, and compliance requirements.
3. **Unified management** – The Azure Portal provides a centralized interface for creating, managing, and monitoring Azure resources.

## Typical Enterprise Use Cases

Azure can be used for enterprise application hosting, Windows-based workloads, databases, identity management, hybrid cloud environments, analytics, and application development. Organizations can manage these resources through the Azure Portal and integrate cloud services with existing Microsoft environments.
