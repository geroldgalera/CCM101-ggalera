# Mission Reflection

Completing this laboratory activity helped me understand the differences and similarities between the three major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Among the three platforms, Google Cloud Platform impressed me the most because of its strong focus on artificial intelligence, machine learning, data analytics, and cloud-native technologies. I also found its services useful for organizations that need scalable infrastructure for modern applications.

AWS, Azure, and GCP have many similarities because they all provide essential cloud computing services such as virtual machines, object storage, databases, networking, identity management, and Kubernetes. They also provide global infrastructure that allows organizations to deploy applications and services in different geographic locations. Although their services have different names and features, they provide similar solutions for common cloud computing requirements.

Business requirements have a major influence on cloud platform selection. Organizations need to consider their budget, existing technologies, application requirements, scalability, security, performance, and geographic needs before choosing a provider. For example, Azure is a practical choice for organizations already using Microsoft technologies, while AWS can be suitable for organizations that need a broad range of services and global infrastructure.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The recommendation should be based on the specific needs and goals of the client. I learned how to analyze different scenarios and match them with appropriate cloud services.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I added research documents, comparison tables, client recommendations, cloud service mappings, Linux investigation results, screenshots, and this reflection. This made my repository more organized and demonstrated my ability to document and present cloud computing activities professionally.
