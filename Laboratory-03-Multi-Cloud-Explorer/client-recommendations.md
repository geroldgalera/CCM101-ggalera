# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is a suitable choice for a startup with a limited budget and expectations for rapid growth. It provides cloud services that can support application development, computing, storage, and scalable infrastructure as the startup grows. GCP can also support cloud-native application development and data-driven workloads. The platform can be used to build an infrastructure that can expand as the mobile application gains more users.

**Recommended Services:**

* Google Compute Engine – for virtual computing resources.
* Google Cloud Storage – for storing application data and files.
* Google Cloud SQL – for managed relational database workloads.

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's enterprise technologies, making migration and management easier for an organization already using the Microsoft ecosystem. The university can also use Azure identity and access services to manage users and access to cloud resources. This makes Azure a practical option for gradually migrating existing services to the cloud.

**Recommended Services:**

* Azure Virtual Machines – for migrating and running server workloads.
* Microsoft Entra ID – for identity and access management.
* Azure SQL Database – for managed relational database workloads.

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is a strong choice for an AI research company because it provides cloud services designed for artificial intelligence, machine learning, data processing, and high-performance computing. The company can use scalable computing resources to run demanding AI and ML workloads. Google Cloud also provides services that support data analytics and cloud-native development. These capabilities make GCP appropriate for a research organization focused on AI and machine learning.

**Recommended Services:**

* Compute Engine – for high-performance virtual computing workloads.
* Google Kubernetes Engine (GKE) – for deploying and managing containerized AI applications.
* Vertex AI – for developing and managing AI and machine learning workloads.

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is a suitable choice for a multinational e-commerce company that needs highly available infrastructure and automatic scaling. AWS provides a broad range of services that can support globally distributed applications, storage, databases, networking, and scalable computing. Its infrastructure can be designed across multiple Availability Zones to improve application availability and fault tolerance. AWS also provides services that can automatically adjust computing capacity based on application demand.

**Recommended Services:**

* Amazon EC2 – for scalable virtual computing resources.
* Amazon S3 – for object storage and application data.
* Elastic Load Balancing – for distributing application traffic across resources.
* Amazon EC2 Auto Scaling – for automatically adjusting compute capacity based on demand.
