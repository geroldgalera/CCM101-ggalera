# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is a cloud computing platform that provides services for computing, storage, databases, networking, analytics, artificial intelligence, security, and application development. Google Cloud provides more than 150 products and services across multiple cloud technology categories.

## Global Infrastructure

Google Cloud operates a global infrastructure designed to support applications and services across different geographic locations. Its infrastructure includes regions and zones, allowing organizations to deploy workloads according to availability, performance, and geographic requirements.

## Cloud Management Console

The Google Cloud console is a web-based management interface for managing Google Cloud resources and services. It provides an organized interface for managing infrastructure, applications, costs, and permissions. Google Cloud also provides customizable IAM permissions for controlling access to resources.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can be used to run applications and workloads.

### 2. Cloud Storage

Cloud Storage provides object storage for data and files.

### 3. Cloud SQL

Cloud SQL is a managed SQL database service for applications.

### 4. Google Cloud IAM

Google Cloud Identity and Access Management (IAM) controls who can access Google Cloud resources and what permissions they have.

## Three Advantages

1. **Strong data and AI capabilities** – Google Cloud provides services for AI/ML, analytics, and large-scale data workloads.
2. **Integrated management** – The Google Cloud console provides a centralized interface for managing cloud services and infrastructure.
3. **Granular IAM** – Google Cloud IAM allows organizations to assign roles and permissions to users, groups, and service accounts.

## Typical Enterprise Use Cases

Google Cloud can be used for virtual machines, web applications, data analytics, databases, AI and machine learning workloads, object storage, and cloud-native applications. Its services such as Compute Engine, Cloud Storage, Cloud SQL, and IAM can be combined to build enterprise applications and infrastructure.
