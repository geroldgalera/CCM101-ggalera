# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory activity focuses on exploring and comparing three major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The mission involves researching their services, infrastructure, strengths, and typical enterprise use cases.

## Mission Objectives

* Explore the major public cloud platforms.
* Identify the core services offered by AWS, Microsoft Azure, and Google Cloud Platform.
* Compare cloud services across different providers.
* Analyze business requirements and recommend appropriate cloud solutions.
* Create professional technical documentation using Markdown.
* Continue developing a well-organized GitHub Cloud Computing Portfolio.

## Cloud Platforms

The three cloud platforms investigated in this laboratory are:

* Amazon Web Services (AWS)
* Microsoft Azure
* Google Cloud Platform (GCP)

## Activities

This laboratory will include cloud platform research, service comparisons, business scenario recommendations, cloud service matching, a multi-cloud decision matrix, Linux investigation using KillerCoda, and a final reflection.

## Cloud Migration Equivalents

If this Linux server were migrated to the cloud, the following services could be used to host it:

| Cloud Provider | Cloud Service | Purpose |
|---|---|---|
| AWS | Amazon EC2 | Hosts Linux virtual machines and provides scalable computing resources. |
| Microsoft Azure | Azure Virtual Machines | Hosts Linux virtual machines and provides configurable computing resources. |
| Google Cloud Platform | Google Compute Engine | Provides virtual machine instances for running Linux workloads. |

### Migration Summary

The Linux server could be migrated to any of the three major cloud platforms using their virtual machine services. Amazon EC2, Azure Virtual Machines, and Google Compute Engine can all provide an environment for running Linux workloads. The final choice would depend on factors such as cost, performance requirements, existing infrastructure, and the organization's preferred cloud ecosystem.
