## Answers to Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services among the three major providers. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It is particularly suitable for organizations already using technologies such as Windows Server, Microsoft 365, and Microsoft identity and directory services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence and Kubernetes because of its data, AI, and cloud-native technologies. Google Kubernetes Engine (GKE) provides managed Kubernetes, while Google Cloud also provides a broad set of AI and machine learning services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Microsoft Azure because it provides a strong combination of cloud infrastructure, enterprise services, and integration with Microsoft technologies. I also think Azure would be useful for organizations that already use Windows Server, Microsoft 365, and Microsoft identity services.

# Cloud Service Matching

| Service Category        | AWS        | Microsoft Azure                | Google Cloud Platform          |
| ----------------------- | ---------- | ------------------------------ | ------------------------------ |
| **Virtual Machine**     | Amazon EC2 | Azure Virtual Machines         | Google Compute Engine          |
| **Object Storage**      | Amazon S3  | Azure Blob Storage             | Google Cloud Storage           |
| **Identity Management** | AWS IAM    | Microsoft Entra ID             | Google Cloud IAM               |
| **SQL Database**        | Amazon RDS | Azure SQL Database             | Cloud SQL                      |
| **Kubernetes**          | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Service Matching Summary

The three major cloud providers offer equivalent services for common cloud computing requirements. Amazon EC2, Azure Virtual Machines, and Google Compute Engine provide virtual machine capabilities, while Amazon S3, Azure Blob Storage, and Google Cloud Storage provide object storage. AWS IAM, Microsoft Entra ID, and Google Cloud IAM provide identity and access management capabilities.

For managed SQL databases, AWS provides Amazon RDS, Azure provides Azure SQL Database, and Google Cloud provides Cloud SQL. For Kubernetes deployments, the equivalent managed services are Amazon EKS, Azure Kubernetes Service (AKS), and Google Kubernetes Engine (GKE).
