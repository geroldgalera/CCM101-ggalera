## Answers to Comparison Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services among the three major providers. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It is particularly suitable for organizations already using technologies such as Windows Server, Microsoft 365, and Microsoft identity and directory services.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence and Kubernetes because of its data, AI, and cloud-native technologies. Google Kubernetes Engine (GKE) provides managed Kubernetes, while Google Cloud also provides a broad set of AI and machine learning services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose Microsoft Azure because it provides a strong combination of cloud infrastructure, enterprise services, and integration with Microsoft technologies. I also think Azure would be useful for organizations that already use Windows Server, Microsoft 365, and Microsoft identity services.
