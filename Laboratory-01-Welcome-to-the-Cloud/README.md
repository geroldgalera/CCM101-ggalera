# Laboratory 01 – Welcome to the Cloud

## Mission Overview
This laboratory activity introduces the basic concepts and practical skills needed to work in a Linux cloud environment.

## Objectives
- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed
- Launched an Ubuntu Linux environment using KillerCoda.
- Created a new Linux user with Bash, a home directory, and sudo access.
- Explored the Linux environment.
- Gathered system information.
- Created and organized files and directories.
- Created Markdown documentation.

## Linux Commands Used
- `whoami`
- `pwd`
- `hostname`
- `cat`
- `uname`
- `lscpu`
- `free`
- `df`
- `mkdir`
- `nano`
- `su`
- `passwd`

## Skills Learned
Through this laboratory activity, I learned how to work with a Linux environment, use basic Linux commands, gather system information, organize files, and document my work using Markdown and GitHub.
