# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity is the first mission in the Cloud Computing course. It focuses on preparing a professional cloud computing workspace by learning how to work inside a Linux environment, organize files and directories, and document technical work using Markdown and GitHub.

## Objectives

* Access a cloud-based Linux environment using KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Organize files and directories using Linux commands.
* Create and maintain a professional GitHub repository.
* Document technical work using Markdown.

## Activities Performed

* Launched an Ubuntu 24.04.4 LTS Linux environment using KillerCoda.
* Created a new Linux user with Bash, a home directory, and sudo access.
* Logged in to the newly created Linux user account.
* Checked the current username, working directory, and hostname.
* Investigated the Linux distribution, kernel version, CPU information, total memory, and available disk space.
* Created and organized the required files and directories.
* Created Markdown documentation for the laboratory activity.
* Created a public GitHub repository for the Cloud Computing Portfolio.

## Linux Commands Used

* `whoami` – displays the current username.
* `pwd` – displays the current working directory.
* `hostname` – displays the hostname of the system.
* `cat /etc/os-release` – displays information about the Linux distribution.
* `uname -r` – displays the kernel version.
* `lscpu` – displays CPU information.
* `free -h` – displays memory information.
* `df -h /` – displays available disk space.
* `useradd` – creates a new Linux user.
* `passwd` – sets or changes a user's password.
* `su` – switches to another user account.
* `mkdir` – creates directories.
* `nano` – creates or edits text files.
* `cat` – displays the contents of a file.

## Skills Learned

Through this laboratory activity, I learned how to access and work with a cloud-based Linux environment. I gained experience using basic Linux commands to navigate the system, manage users, organize files, and gather system information. I also learned how to use Markdown for technical documentation and GitHub to create and maintain a Cloud Computing Portfolio.
